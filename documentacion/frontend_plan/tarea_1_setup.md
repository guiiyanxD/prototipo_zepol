# Tarea 1: Setup e Inicialización del Proyecto

## Objetivo
Establecer la base del proyecto Frontend utilizando tecnologías modernas, optimizadas para rendimiento y preparadas para escalabilidad.

## Stack Tecnológico Recomendado
- **Framework**: React 18 con Vite (ofrece un HMR ultrarrápido y builds optimizados).
- **Estilos**: Tailwind CSS v3 (para maquetación rápida, utilidades de diseño y responsividad).
- **Animaciones**: Framer Motion (fundamental para cumplir con el requisito de microanimaciones fluidas).
- **Enrutamiento**: React Router v6.
- **Llamadas a API**: Axios o React Query (para conectar con `/api/quotes` y demás endpoints del backend).

## Acciones a realizar
1. Ejecutar el andamiaje del proyecto en la carpeta `frontend/` (o cliente) dentro de la raíz del proyecto.
2. Instalar y configurar Tailwind CSS.
3. Instalar Framer Motion, React Router y Lucide React (para iconos limpios y modernos).
4. Configurar alias de rutas (ej. `@/components`, `@/assets`).
5. Limpiar archivos base y dejar el esqueleto listo para el desarrollo del Sistema de Diseño.
