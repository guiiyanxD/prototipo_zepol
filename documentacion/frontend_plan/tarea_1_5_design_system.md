# Tarea 1.5: Configuración del Sistema de Diseño (Tokens)

## Objetivo
Traducir las especificaciones lógicas definidas en `DESIGN_SYSTEM.md` a código real dentro del proyecto frontend.

## Acciones a realizar
1. Modificar `tailwind.config.js` para incluir los nuevos colores (Primary: `#1E3A8A`, Secondary: `#0F172A`, Accent: `#0891B2`, Background: `#F1F5F9`).
2. Configurar la tipografía global usando Google Fonts (`Inter`).
3. Definir las variables de modo oscuro (si se decide activar) en un archivo global de CSS (`index.css`).
4. Configurar las clases base de elevación (sombras suaves) y radios (`rounded-lg`) para usarse como presets en los componentes.
