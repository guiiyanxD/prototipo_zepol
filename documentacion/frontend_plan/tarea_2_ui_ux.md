# Tarea 2: Diseño del Sistema (UI/UX) y Componentes Base

## Objetivo
Crear una librería de componentes visuales coherente con la identidad corporativa de **Zepol Ltda.**

## Lineamientos de Marca (Zepol)
1. **Colores Corporativos** (Extraídos del isotipo):
   - **Azul Marino/Índigo**: Color primario para textos de alto contraste y logotipos.
   - **Gama de Acentos**: Amarillo, Naranja, Magenta, Verde, Celeste (representan la versatilidad de impresión y la cuatricromía). Se usarán sutilmente en hover states, badges, o microinteracciones.
   - **Fondo**: Blancos y grises muy claros (para transmitir limpieza industrial y grado alimenticio).
2. **Tipografía**: Sans-serif moderna y legible (ej. Inter, Roboto o Montserrat) para mantener el tono corporativo e industrial.

## Componentes a Desarrollar
1. **Layout / Estructura**: `Navbar` (Transparente a sólido con scroll) y `Footer` (Con datos de contacto de La Paz, Bolivia).
2. **Botones (Call to Action)**: 
   - Botón Primario: "Cotizar Ahora" (Con microanimación de scale o flecha al hacer hover).
   - Botón Secundario: "Conocer más".
3. **Tarjetas (Cards)**: Para mostrar la gama de productos (BOPP, Bilaminados, Polivac, etc.) con ligeras animaciones de elevación.
4. **Form Inputs**: Inputs de alta calidad visual para el cotizador, con focus states claros.
